## 现在查看

1. 双击根目录的 `启动本地网站.cmd`，保持服务运行。
2. 用 Edge 打开 <http://127.0.0.1:8768>。
3. 登录邮箱填写 `owner@haoke.local`，获取验证码，再点击页面里的“查看本次验证码”。验证后可进入管理后台。

当前为开发邮件收件箱，**不会发送真实邮件**。普通玩家可用其他符合邮箱格式的地址测试注册。管理员邮箱来自环境配置；没有默认管理员密码，首次验证该邮箱时建立管理员账号。请勿向公网暴露开发模式。

本机 Python 3.12 与依赖已经可用，前端已构建。换电脑时需要 Python 3.11+、Node.js 22 LTS（或兼容版本）和 npm，运行 `首次安装依赖.cmd`。它只在项目 `.venv` 安装依赖，再用锁文件安装和构建前端。macOS/Linux 可执行 `python3 scripts/setup_local.py`，然后 `.venv/bin/python scripts/run_local.py`。这些平台未做真机验证。

命令行启动与检查：

```powershell
py -3 scripts/run_local.py --check
py -3 scripts/run_local.py
```

关闭自己启动的服务终端或按 Ctrl+C 停止服务；不需要关闭浏览器。启动器发现同端口已运行本服务时不会启动第二份。默认只监听本机。

## 项目与数据

前端 React/Vite；后端 FastAPI；SQLite WAL。一个进程即可运行，适合本地验收和初期小规模部署。实时房间广播在进程内，**当前必须单 worker**；扩大负载前再引入共享广播与数据库方案。房间服务和战斗模拟是两层，不可直接用网页消息接口承载粒子同步。

- `frontend/src/`：页面、交互和样式；`frontend/public/`：字体与表情。
- `backend/`：账号、房间、管理、权限和持久化。
- `data/platform.sqlite3`：实际本地账号和设置；`data/.app-secret`：本地自动产生的应用秘密。均不进入源码提交。
- `.env.example`：配置模板；需要自定义时创建 `.env`，不要公开其中凭证。
- `tests/`：隔离数据库测试；`evidence/`：截图与测试记录；重启测试专用数据库位于 `evidence/restart-check/`，与真实预览数据库分离。

首次启动初始化 schema；migrations 1–5 保留旧用户与设置，新增原生接入/队列/中继/战斗状态、Liquid Wars 单人开局规则及正式接入标记。服务重启关闭不能续传的在途战斗；不会清空用户和设置。生产数据库与本地预览数据独立。此任务未创建备份。
