## 先做同机位的可操作对照片段

沿用现有 Android 工程、实时 3D 棋盘和手势。以 `scene_contract.json` 为尺度与坐标依据，接入样片同一布局、机位、矿板、数字、矿灯与一次踩雷。先在手机上比较材质、灯光层次、数字辨识度和爆炸节奏，通过后再扩展。

`.blend` 中的 Cycles 体积和节点不能直接当作 Android 实时材质。按手机性能烘焙表面与静态光照、限制碎片实例、将尘土转为透明图集；保留原始可编辑美术与声音。可见几何和点选边界必须同步更新，不能只替换模型。

## 玩法范围

| 模式 | 必须实现的规则与完成条件 |
| --- | --- |
| 经典扫雷 | 独立入口，保留原尺寸、难度、雷数及规则；正确标记全部地雷且无误标获胜，触雷失败。 |
| 矿井撤离 | 从第一层入口打开通往最底层出口的安全路线；同层上下左右、相邻层同坐标连通。制作跨层教学、路线取舍、断层绕行三关，路线打通获胜。 |
| 无猜解谜 | 固定安全起点；用求解器验证只凭公开线索可通关。提示先指出相关格，再解释排除依据，不把已知隐藏雷位当作公开推理。 |
| 断层矿井 | 缺角、中央空洞、错层布局。缺失格清楚可见，不参与选格、邻雷计数或路线连通。 |
| 有限扫描 | 每局两次，只对已开的数字格使用；将总数拆为本层雷数与相邻层雷数，不直接透露具体雷位。 |
| 每日同图 | 同日固定棋盘和安全起点，重试保持同一局面；本地记录用时、误标和提示次数。将日期口径、种子版本和棋盘生成规则一起持久化，避免恢复或升级时悄然换图。 |

## 所有模式共同的行为约束

- 只统计同层上下左右和紧邻上下层同坐标，最多六邻格。首个实际打开的格子安全；自动展开可跨层且保留旗帜。
- 支持 2–8 层，默认 5×5×2，最大 15×15×8。只有当前层参与选格；旋转、缩放、快速换层与动作结束不应误开格或误插旗。
- 本样片制作坐标的 `k=0` 位于下方。撤离模式的入口与出口要按实际空间高低定义，不能直接把数组下标 0 当作最上层；接入时统一界面层号、空间层位和数据索引的映射，并验证相邻层连通。
- 保留全局与当前层视图、层号和上下层按钮，单击选格、底部开格及插旗操作；本版采用选格后按钮操作；可选的双击/长按快捷开格未启用。
- 切后台暂停计时；恢复同一任务时恢复棋盘、旗帜、当前层、计时和模式进度。重新进入已失败对局不能再次触发爆炸与声音。
- 音效开关、减弱闪光和震屏选项必须同时作用于首次触发、恢复和重开路径。停止或切后台后不残留音频播放。
- 首页、选关、局内反馈、结算、重开全部连通，简中与英文一致。扫描次数、提示计数和每日记录需随对局正确保存，不能只处理界面入口。
